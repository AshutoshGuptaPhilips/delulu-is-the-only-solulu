# delulu-is-the-only-solulu
The goal of Dr. Solulu is not to diagnose or cure mental illness, but to help individuals better understand their thoughts, emotions, and behavioral patterns while providing useful information that can complement professional care.

## Custom Agent Service

A dedicated REST-based custom agent is available in the agent folder.

- Setup and usage: agent/README.md
- Prompt customization: agent/config/system-prompt.md
- Quality rubric: agent/config/rubric.json
- Output schema: agent/config/output-schema.json
